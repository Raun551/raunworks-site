System Beneath Publisher

System Beneath Publisher is a private publishing tool for the System Beneath YouTube channel. It is operated by Raunaq Malik under raunworks.work.

What it does

The tool runs on the channel owner's own computer. It uses YouTube API Services to:

  • upload finished videos to the System Beneath channel;
  • set each video's title, description, privacy status and thumbnail;
  • upload captions for each video;
  • read back the status of videos it has uploaded.

It is not a public service. There are no user accounts and no sign-up. The only Google account it is authorized to act for is the account that owns the System Beneath channel.
