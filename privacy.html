Privacy Policy

This policy covers System Beneath Publisher (the "tool"), operated by Raunaq Malik ("we"). By authorizing the tool to access a Google account, you agree to this policy.

YouTube API Services

The tool uses YouTube API Services. Google's handling of your information is described in the Google Privacy Policy.

What information the tool accesses

The tool is used only with the Google account that owns the System Beneath YouTube channel. With that account's permission, it accesses:

  • the channel's identifier and basic channel details;
  • videos, captions and thumbnails that the tool uploads, and their metadata (title, description, privacy status, processing status);
  • an OAuth access token and refresh token issued by Google.

The tool does not access comments, subscribers, messages, contacts, payment details or any other account's data.

How the information is used

  • To upload and update videos, thumbnails and captions on the System Beneath channel.
  • To check that each upload succeeded and to record which video ID belongs to which production.

We do not use the information for advertising, and we do not sell it.

How the information is stored

  • OAuth tokens and the client secret are stored in the operating system's secure credential store (macOS Keychain) on the operator's computer. They are never written to logs or to the code repository.
  • Video IDs and upload status are stored in a local database on the operator's computer.
  • Stored authorized data from YouTube API Services is deleted or refreshed at least every 30 days.

Sharing

We do not share information obtained through YouTube API Services with any third party, except Google itself as needed to call the API.

Cookies, ads and third-party content

The tool is a command-line program. It does not set cookies, serve ads, or show third-party content. This website does not use cookies or analytics.

Revoking access and deleting data

  • You can revoke the tool's access at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • After access is revoked, we delete all stored data obtained through YouTube API Services within 30 days.
  • You can ask us to delete stored data at any time by contacting us. We act on deletion requests within 7 days.
